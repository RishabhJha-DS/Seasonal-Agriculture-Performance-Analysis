Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Jupyter Notebook

Key Findings
Loss-making farms rise from 42% (Kharif) to 51% (Rabi) to 64.5% (Zaid) — profitability drops sharply across seasons.
Crop choice matters more than season: Chilli and Sugarcane stay profitable every season; Rice, Wheat, and Maize run at a loss every season.
Kharif has the highest rainfall but also the highest disease/pest risk (~54%).
Flood irrigation is the least water-efficient method in every season.
